# Tone and style

This app moves browser tabs between a person's own devices. The user owns every
device involved, so nothing here is about sharing with other people.

Plain, short, and calm. Say what happened and what the user can do about it. No
exclamation marks. Never blame the user for a failure.

## de

Address the user with "du", not "Sie". This is a personal tool, not enterprise
software.

Do not use gender-inclusive forms such as "Nutzer:innen". Prefer a neutral noun:
"Gerät", "Browser", "Tab".

## ru

Address the user informally, as one person. Prefer the imperative.
